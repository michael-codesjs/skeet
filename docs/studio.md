# Studio Interface

The Skeet Studio is a professional, AI-powered Non-Linear Editor (NLE). It combines traditional timeline precision with a conversational multi-agent workflow.

## Layout Overview

The interface is divided into four primary regions:

### 1. Media Library (Left Sidebar)

- **Scout Search**: A semantic search bar for finding moments, tags, and vibes across all uploaded media.
- **Media Filters**: Quick toggles for All, Photos, Videos, and Audio assets.
- **Clip Grid**: Visual thumbnails of all assets with duration overlays.

### 2. Primary Monitor (Center)

- **Video Canvas**: The main preview area for playback.
- **Transport Controls**: Persistent playback controls including 10s skip, play/pause, and fullscreen toggle.
- **Status Overlay**: Contextual information about the active clip or sequence state.

### 3. Skeet Assistant (Right Sidebar)

- **Conversational Interface**: The heart of the NLE. Users can chat with the Skeet Assistant to perform complex tasks.
- **Capabilities**:
  - "Scout for hero shots in the drone footage."
  - "Orchestrate a 15-second sequence with high energy."
  - "Apply a cinematic color grade to the whole timeline."
- **Mention System**: Use `@` to mention specific clips or tracks in your prompts.

### 4. Sequence Timeline (Bottom)

- **Track Management**: Multi-track support for Video and Audio.
- **Toolbar**: Tools for Selecting, Cutting, and Retiming clips.
- **Timecode**: Precise SMPTE timecode display and project duration.
- **Zoom Control**: Fluid slider for navigating long sequences.

## Status & Hardware

The footer provides real-time status of the distributed agents:

- **AI Director Online**: Indicates the connection to the Gemini backbone.
- **Agent State**: Standby, Scouting, or Rendering.
- **Keyboard Shortcuts**: Visible reminders for `SPACE`, `/` (Search), and `CMD+K` (Command Palette).
